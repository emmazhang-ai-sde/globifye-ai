# Archived SIP Bridge Experiments

These files are older bridge or transport experiments kept for reference only.
Do not use them for the current demo flow.

Use the latest runtime from the parent directory:

```bash
venv/bin/python -u sip/scripts/stt_bridge_ai_human_transfer.py
```

Archived files:

- `step2_stt_bridge.py` - earlier STT/LLM/TTS bridge before AI-human-AI handoff work.
- `poc_chan_websocket_echo.py` - chan_websocket proof of concept.
- `poc_pipecat_agent_transport.py` - Pipecat agent transport proof of concept.
- `poc_pipecat_transport.py` - Pipecat transport proof of concept.
